# Features

Use this page to choose the Cloudeval feature guide that matches what you are trying to do: generate diagrams, edit Infrastructure as Code, collaborate with teammates, export diagrams, or review upcoming capabilities.

## Core Features

### [Export & Share](export.md)

Export your diagrams in multiple formats:

- **PNG** - High-resolution images for presentations
- **SVG** - Scalable vector graphics
- **Visio (VSDX)** - Microsoft Visio format
- **draw.io** - Draw.io XML format
- **PDF** - Print-ready documents

Share diagrams via links, embed in documentation, or download for offline use.

**[Learn About Export →](export.md)**

### [Collaboration](collaboration.md)

Work together with your team:

- Real-time collaboration
- Comments and annotations
- Version history
- Team permissions
- Activity tracking

**[Start Collaborating →](collaboration.md)**

### [Web IaC Editor](web-editor.md)

Edit Infrastructure as Code directly in your browser:

- Syntax highlighting
- Auto-completion
- Error detection
- Multi-file support
- Live diagram updates

**[Try the Editor →](web-editor.md)**

- **Automated diagram generation** - Generate diagrams from Infrastructure as Code.
